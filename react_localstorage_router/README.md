# React Lab — Todo + localStorage + React Router

Готовый учебный проект по материалу частей 7–8. Проект создан на React 18 и Vite, маршрутизация — React Router v6.

## Запуск локально

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev
```

Открой адрес, который покажет Vite (обычно `http://localhost:5173`).

Сборка для production:

```bash
npm run build
npm run preview
```

## Что реализовано

### Часть 7 — localStorage

- Todo: добавление, выполнение, удаление, фильтрация и очистка задач.
- Задачи сохраняются между перезагрузками через кастомный `useLocalStorage`.
- Хук использует ленивую инициализацию, `JSON.parse` / `JSON.stringify` и `try/catch` при чтении и записи.
- Счётчик с постоянным хранением.
- Переключатель светлой и тёмной темы с сохранением выбора.
- Черновик заметки с debounce 500 мс.
- Очистка задач запрашивает подтверждение через `window.confirm`.

### Часть 8 — React Router

- `BrowserRouter`, `Routes`, `Route` и общий layout через `Outlet`.
- Навигация `Link` / `NavLink`.
- Главная `/` и страница `/about`.
- Список пользователей `/users` и динамический профиль `/users/:userId` через `useParams`.
- Хлебные крошки и обработка неизвестного ID.
- Список публикаций `/posts` и динамическая страница `/posts/:id`.
- Защищённый маршрут `/admin` с редиректом через `Navigate`.
- Фильтр пользователей по городу через query-параметр `?city=Москва` и `useSearchParams`.
- Страница 404 для неизвестных URL.

## Проверка упражнений

1. Добавь несколько задач и обнови страницу — список должен сохраниться.
2. Отметь задачу выполненной, обнови страницу — статус сохранится.
3. Измени счётчик и тему, затем обнови страницу.
4. Введи текст в черновик и подожди 500 мс — статус изменится на «Сохранено».
5. Открой `/users`, затем выбери город — URL изменится на `/users?city=...`.
6. Открой профиль пользователя и проверь динамический URL и хлебные крошки.
7. Открой `/posts/1` и `/posts/999`.
8. Открой `/random` — должна появиться страница 404.
9. В `src/App.jsx` измени `const isAdmin = true` на `false` и открой `/admin` — приложение перенаправит на главную.
