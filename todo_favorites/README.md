# Мои задачи — Angular

Простое приложение для списка задач с возможностью добавлять задачи в избранное.

## Возможности

- добавление задач;
- отметка задач как выполненных;
- удаление задач;
- добавление и удаление задач из избранного;
- счётчик избранного, который обновляется автоматически;
- очистка избранного при удалении задачи.

## Запуск

Понадобится Node.js 20.19+ или 22.12+.

```bash
npm install
npm start
```

Откройте в браузере `http://localhost:4200`.

## Сборка

```bash
npm run build
```

## Как работает избранное

Сервис `FavoritesService` хранит ID избранных задач в `Set<number>`. Метод `toggle()` добавляет задачу в избранное или убирает её оттуда. Метод `getCount()` возвращает количество избранных задач.

Счётчик использует Angular Signals и автоматически обновляется при изменении избранного.

При удалении задачи компонент вызывает `remove()` у `FavoritesService`, поэтому удалённая задача не остаётся в счётчике.
