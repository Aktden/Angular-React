# Мини-заметки - Angular



## Что реализовано

- **Главная** (`/`) - приветственная страница «Добро пожаловать в Мини-заметки».
- **Заметки** (`/notes`) - загрузка записей из API, индикатор загрузки, обработка ошибки сети, пустое состояние и удаление.
- **Создать** (`/create`) - реактивная форма с проверками: заголовок от 3 символов, текст от 5 символов.
- **API** - `GET`, `POST` и `DELETE` через `NoteService`.
- **Навигация** - Angular Router без перезагрузки страницы; неизвестный адрес перенаправляется на главную.
- **Сборка** - production-конфигурация Angular CLI.

## Требования

- Node.js 20.19+ или 22.12+.
- npm 10+.

## Установка

Откройте терминал в папке проекта и выполните:

```bash
npm install
```

## Запуск приложения

### Вариант 1 - одной командой

```bash
npm run dev
```

Команда одновременно запускает Angular и `json-server`.

- Приложение: http://localhost:4200
- API: http://localhost:3000/notes

### Вариант 2 - в двух терминалах

Терминал №1 - локальный API:

```bash
npm run api
```

Терминал №2 - Angular:

```bash
npm start
```

Начальные записи находятся в корневом файле `db.json`. Создание и удаление заметок изменяют этот файл через `json-server`.

## Проверка API

Откройте http://localhost:3000/notes. Должен отобразиться JSON-массив заметок.

## Production-сборка

```bash
npm run build
```

Результат появится в `dist/mini-notes/browser/`.

Для локальной проверки собранной версии:

```bash
npx http-server dist/mini-notes/browser -p 8080
```

Откройте http://localhost:8080.

## Основные проверки из задания

1. Открыть `/`, перейти по всем трём ссылкам - страницы переключаются без перезагрузки.
2. Запустить API и открыть `/notes` - отображаются две начальные заметки.
3. Остановить API и обновить `/notes` - появится сообщение об ошибке, загрузка не зависнет.
4. Открыть `/create` - кнопка недоступна до корректного заполнения обоих полей; после касания полей отображаются ошибки валидации.
5. Создать заметку - запись появится в `db.json` и после перехода на `/notes` будет в списке.
6. Удалить заметку - она исчезнет из списка и из `db.json`.
7. Выполнить production-сборку и открыть её через `http-server`.
