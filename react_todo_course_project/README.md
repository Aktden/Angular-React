# Focus — React Todo

Учебный проект по Частям 3 и 4: `useState`, события, управляемые компоненты, списки, условный рендеринг, фильтрация и стилизация.

## Возможности

### Todo-приложение
- Добавление задач с приоритетом: низкий, средний, высокий.
- Отметка задачи как выполненной и удаление.
- Редактирование названия с проверкой на пустую строку.
- Фильтры по статусу и приоритету.
- Поиск по названию без учёта регистра.
- Сортировка по дате добавления или алфавиту.
- Счётчики всех, активных и выполненных задач.
- Прогресс-бар выполнения.
- Массовые действия: отметить все, удалить выполненные, очистить список.
- Автоматическое сохранение задач в `localStorage`.

### Упражнения Части 3
- Счётчик с настраиваемым шагом.
- Переключение светлой и тёмной темы.
- Форма входа с активной кнопкой только при заполненных полях.
- Список покупок с добавлением и удалением элементов.

## Запуск локально

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev
```

Vite выведет локальный адрес приложения (обычно `http://localhost:5173`).

## Проверка production-сборки

```bash
npm run build
npm run preview
```

Готовая сборка появится в каталоге `dist/`.

## Примечания

- Серверная часть и регистрация пользователей не входят в задание: форма входа демонстрирует управляемые поля и обработчик `onSubmit`.
- Задачи сохраняются только в браузере, в `localStorage`. Чтобы очистить сохранённые данные, используй кнопку «Очистить всё» или очисти хранилище сайта в настройках браузера.
